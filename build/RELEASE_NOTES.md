## 岚读 · Windows 桌面 EPUB 阅读器

**下载后直接使用，无需安装 Node.js、Python 或其他开发环境。**

### 下载哪个文件？

- **`LanRead-0.2.0-Windows-x64-Setup.exe`**：安装版。双击安装，支持选择目录和创建桌面快捷方式。安装向导会检查系统版本；完整运行环境已经内置，不会安装或修改系统 Node.js。
- **`LanRead-0.2.0-Windows-x64.zip`**：免安装版。右键 → 全部解压，进入解压目录，双击 **`岚读.exe`**。请保留所有 DLL、`resources` 等文件，不要只复制 EXE。
- **`SHA256SUMS.txt`**：下载文件的 SHA-256 校验值。

适用于 Windows 10 / 11 x64，首次运行无需联网。

### 本次更新

- 修复系列内册序被书库排序覆盖的问题；自动排序优先册序，再识别中文、英文书名及文件名编号，最后按自然名称排列。
- 可以先创建空系列，再将单本书拖到系列卡片中。
- 系列内可切换「自动册序 / 手动拖拽」，拖拽顺序重启后保留，也支持箭头移动。
- 没有明确封面的 EPUB，按章节阅读顺序提取第一张可用图片；既有书库也会补全。
- EXE 安装向导增加「更新已有岚读」，可以指定旧版安装或 ZIP 解压目录。书籍、进度、书签备注及阅读设置保留在原数据目录。

### 功能

- EPUB 2/3 阅读、目录、分页及进度保存。
- 封面、作者、系列堆叠，支持手动设置系列及册序。
- 独立书签标题与备注，自动保存。
- 淡蓝色界面、简短过渡动画；字体、字号、行距与背景配色可调。
- 全部书籍、书签和设置保存在本机；具体位置在应用“阅读设置”里查看。ZIP 免安装版同样使用应用数据目录，移动程序目录不会搬动书库。

尚未配置 Windows 代码签名，文件会显示未知发布者。主要支持未加密的可重排 EPUB；DRM、复杂固定版式及交互式 EPUB 不保证兼容。

GitHub 自动显示的 **Source code (zip/tar.gz)** 是开发源码，普通用户请下载上面的 EXE 或 Windows ZIP 成品。
